# Samsung CSC features

The CSC table, which carriers fill in and the framework reads, and which has to be answered rather than written on a device that does not let an app change it.

580 keys, grouped by the area they belong to. Each carries the value the references give for it where they agree on one, or the value this device holds where they do not. Where no reference describes a key, its note is a paraphrase of the key name; the `description_source` field in the data says where a note came from.
